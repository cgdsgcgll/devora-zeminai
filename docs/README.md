## Tarihsel kayıtlar

`*_VALIDATION.md`, `IMPLEMENTATION_REPORT.md`, `LLM_IMPLEMENTATION_REPORT.md`,
`DEV_HISTORY.md` önceki fazların tarihli test/karar kayıtlarıdır; güncel test
toplamı veya mevcut ürün kapsamı olarak okunmamalıdır. `SECURITY_REVIEW.md` ve
`PRODUCTION_READINESS.md` de tarihli audit sonuçlarını içerir; deployment
gereksinimleri için güncel DEPLOYMENT rehberini kullanın. `VISION.md` hedef
kapsamdır, tamamlanmış özellik listesi değildir.

Yerel oturum dökümleri, geçici QA veritabanları, ekran görüntüleri ve çalışma
ağacı raporları dokümantasyon değildir; ignored `work/` altında tutulur.
